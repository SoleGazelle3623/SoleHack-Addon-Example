SoleHack 1.0 Addon Example

I made this example addon for people to use to make their
own modules and features in the SoleHack Client.

If you are going to use mixins or anything like that, add it yourself.

To import a addon to use in game, go to .minecraft, go to the SoleHack Folder, and then 
go to the addons folder to paste your addon in there to use.
